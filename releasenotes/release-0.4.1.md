# Akex 0.4.1

## Behoben

- Das neue App-Icon wird nun auch nach einem Update korrekt in der Windows-Taskleiste angezeigt.
- Neue Tabs starten wieder im Grundverzeichnis statt im Verzeichnis des aktuell geöffneten Tabs.

## Verbessert

- Tabs können aus Akex herausgezogen und als eigenes Fenster geöffnet werden.
- Beim Ziehen von Dateien über einen anderen Tab wird dieser nach kurzem Hover automatisch geöffnet.
- Dateien können direkt auf einen Tab oder in die freie Fläche des geöffneten Zielordners gezogen werden.
